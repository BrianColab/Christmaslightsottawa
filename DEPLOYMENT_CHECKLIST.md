# Deployment Checklist

## Before launch

- [ ] Confirm final logo.
- [ ] Confirm favicon.
- [ ] Confirm real images.
- [ ] Confirm form destination email.
- [ ] Add `RESEND_API_KEY`.
- [ ] Add `QUOTE_TO_EMAIL`.
- [ ] Confirm `QUOTE_FROM_EMAIL`.
- [ ] Confirm analytics IDs if used.
- [ ] Confirm Google Search Console access.
- [ ] Confirm Google Business Profile link.
- [ ] Confirm privacy policy.
- [ ] Confirm terms or service disclaimer if needed.
- [ ] Confirm domain.
- [ ] Confirm hosting platform is Railway.

## Technical checks

- [ ] Run available checks.
- [ ] Test quote form with valid data.
- [ ] Test quote form validation errors.
- [ ] Test phone links.
- [ ] Test mobile navigation.
- [ ] Test `/sitemap.xml`.
- [ ] Test `/robots.txt`.
- [ ] Test service-area pages.
- [ ] Test blog posts.

## Search launch

- [ ] Submit sitemap after launch.
- [ ] Inspect homepage in Google Search Console.
- [ ] Inspect request quote page.
- [ ] Inspect blog index.
- [ ] Inspect key service-area pages.

## Current commands

- Build command: none required.
- Start command: `npm start`.
- Local preview: `npm run dev`.
